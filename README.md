# Google Form แบบทดสอบก่อนเรียน รายวิชา 220104

สคริปต์ `create_quiz_form.gs` ใช้สร้าง Google Form แบบ Quiz 30 ข้อ ข้อละ 1 คะแนน ตรวจคะแนนอัตโนมัติ และเก็บชื่อ-สกุลกับรหัสนักศึกษา
ข้อความและเฉลยถอดมาจากไฟล์ .docx ต้นฉบับตรงตามเดิม โดยใช้ตัวเลือกที่เป็นตัวอักษรสีแดงเป็นเฉลย

## วิธีสร้างฟอร์ม

1. เปิด https://script.google.com แล้วกด **New project**
2. ลบโค้ดเดิม แล้ววางเนื้อหาทั้งหมดของ `create_quiz_form.gs`
3. เลือกฟังก์ชัน `createQuizForm` แล้วกด **Run** จากนั้นอนุญาตสิทธิ์ (Review permissions → Allow)
4. เปิด **Execution log** แล้วคัดลอกลิงก์
   - "ลิงก์สำหรับแก้ไขฟอร์ม" ใช้เองสำหรับแก้ไข
   - "ลิงก์สำหรับส่งนักศึกษา" ใช้ส่งให้ผู้เรียน
5. ในฟอร์ม ให้ตรวจที่ **Settings → Quizzes** ว่า
   - Release grades ตั้งเป็น *Immediately after each submission*
   - ติ๊กตัวเลือกที่ต้องการให้ผู้เรียนเห็นใน Respondent can see (Missed questions / Correct answers / Point values)

## ข้อจำกัด

- Google Forms จับเวลา 45 นาทีเองไม่ได้ ต้องคุมเวลาด้วยวิธีอื่น
- ถ้าจะใช้ข้อสอบชุดนี้เป็นแบบทดสอบหลังเรียนด้วย ให้ปิด *Correct answers* เพราะเมื่อผู้เรียนเห็นเฉลยแล้ว ผลสอบหลังเรียนจะเชื่อถือไม่ได้
- ถ้าต้องการแก้เฉลย ให้แก้ค่า `answer` ของข้อนั้นใน `QUESTIONS` แล้ว Run ใหม่ ระบบจะสร้างฟอร์มใหม่ขึ้นมาอีกหนึ่งชุด
