# ระบบสอบออนไลน์จับเวลา: แบบทดสอบก่อนเรียน รายวิชา 220104

เว็บสอบที่สร้างด้วย Google Apps Script (ในโฟลเดอร์ `webapp/`)

- ผู้สอบกรอกชื่อ-สกุลและรหัสนักศึกษา แล้วทำข้อสอบ 30 ข้อ ข้อละ 1 คะแนน
- ให้เวลา **30 นาที** เมื่อหมดเวลา ระบบส่งคำตอบให้อัตโนมัติ ตอบได้กี่ข้อก็คิดคะแนนเท่านั้น
- เวลาเริ่มนับถูกบันทึกไว้บนเซิร์ฟเวอร์ ถึงจะรีเฟรชหรือปิดแล้วเปิดใหม่ เวลาก็ยังเดินต่อ ไม่ได้เวลาเพิ่ม (แต่จะนับเป็นการออกจากหน้าสอบ)
- คำตอบที่ส่งมาหลังหมดเวลา (เผื่อเน็ตช้าให้ 60 วินาที) จะไม่ถูกนับ ระบบใช้เฉพาะคำตอบที่บันทึกไว้ก่อนหมดเวลา
- รหัสนักศึกษาหนึ่งรหัสสอบได้ครั้งเดียว
- **ห้ามออกจากหน้าสอบ:** ถ้าผู้สอบสลับแท็บ สลับแอป ย่อหน้าต่าง คลิกไปหน้าต่างอื่น (เช่น เปิด AI แบ่งจอข้างกัน) หรือปิดแล้วเปิดใหม่
  - ครั้งแรก ขึ้นคำเตือนเต็มจอ
  - ครั้งที่สอง ระบบส่งคำตอบทันทีและตัดสิทธิ์ ได้คะแนนเท่าที่ตอบไว้
  - ทุกครั้งบันทึกลงชีต ว่าออกกี่ครั้ง ตอนไหน และหายไปกี่วินาที
- **ห้ามคัดลอก:** เลือกข้อความ คัดลอก คลิกขวา และสั่งพิมพ์หน้าข้อสอบไม่ได้
- ส่งแล้วเห็นคะแนนและเฉลยทันที ผลสอบทุกคนบันทึกลง Google Sheet โดยอัตโนมัติ
- เฉลยเก็บอยู่ฝั่งเซิร์ฟเวอร์ ผู้สอบดูเฉลยระหว่างสอบไม่ได้

ข้อสอบและเฉลยใช้ตามไฟล์ .docx ต้นฉบับทุกประการ (เฉลยคือตัวเลือกที่เป็นตัวอักษรสีแดง)

## วิธีติดตั้ง (ทำครั้งเดียว ใช้เวลาประมาณ 5 นาที)

1. เปิด https://script.google.com แล้วกด **New project** และตั้งชื่อโปรเจกต์ เช่น `สอบ 220104`
2. สร้างไฟล์ 3 ไฟล์ แล้ววางเนื้อหาจากโฟลเดอร์ `webapp/`

   | ไฟล์ใน Apps Script | วิธีสร้าง | วางเนื้อหาจาก |
   |---|---|---|
   | `Code.gs` | มีอยู่แล้ว ลบโค้ดเดิมทิ้งก่อน | `webapp/Code.gs` |
   | `Questions.gs` | กด **+** → Script แล้วตั้งชื่อ `Questions` | `webapp/Questions.gs` |
   | `Index.html` | กด **+** → HTML แล้วตั้งชื่อ `Index` | `webapp/Index.html` |

3. เลือกฟังก์ชัน `setup` แล้วกด **Run** และอนุญาตสิทธิ์ (Review permissions → เลือกบัญชี → Advanced → Go to … → Allow)
   ระบบจะสร้าง Google Sheet ชื่อ "ผลสอบ - …" ไว้ใน Drive ของบอส โดยลิงก์ของชีตแสดงใน Execution log
4. กด **Deploy → New deployment** → ที่รูปเฟือง เลือก **Web app** แล้วตั้งค่า
   - Execute as: **Me**
   - Who has access: **Anyone** (ผู้สอบไม่ต้องล็อกอิน Google)
5. กด **Deploy** แล้วคัดลอก **Web app URL** ส่งให้ผู้เรียน

ก่อนใช้จริง ควรเปิดลิงก์แล้วลองสอบเองสักครั้งด้วยรหัสทดลอง แล้วลบแถวนั้นออกจากชีต

## การใช้งานระหว่างสอบ

- **ดูผลสอบ:** เปิด Google Sheet ที่ได้จากข้อ 3 จะเห็นเวลาเริ่ม เวลาส่ง สถานะ คะแนน และคำตอบรายข้อของแต่ละคน
- **ให้ผู้สอบสอบใหม่:** ลบแถวของรหัสนั้นในชีต
- **ปิดรับการสอบ:** Deploy → Manage deployments → Archive
- **เปลี่ยนค่าตั้ง:** แก้ใน `Code.gs` แล้วสร้าง New version ตามขั้นตอนด้านล่าง
  - `durationMinutes` เวลาสอบ (นาที)
  - `showAnswerKey` แสดงเฉลยหลังส่งหรือไม่
  - `allowedLeaves` จำนวนครั้งที่ออกจากหน้าสอบได้โดยแค่ถูกเตือน ตั้งเป็น `0` = เด้งออกตั้งแต่ครั้งแรก
  จากนั้นไปที่ Deploy → Manage deployments → ✏️ → Version: **New version** → Deploy (ลิงก์เดิมยังใช้ได้)

## ข้อจำกัด

- **กันโทรศัพท์เครื่องที่สองไม่ได้:** นักศึกษาถ่ายรูปจอแล้วถาม AI ได้ ซอฟต์แวร์บนเครื่องที่ใช้สอบมองไม่เห็นอุปกรณ์อื่น ทางเดียวคือสอบในห้องที่มีคนคุมและเก็บโทรศัพท์
- **แบ่งจอยังพอดูได้:** ถ้าเปิด AI แบ่งจอ ผู้สอบยังเหลือบมองอีกหน้าต่างได้โดยไม่ต้องคลิก แต่ต้องคลิกเมื่อจะพิมพ์ถาม ซึ่งระบบจับได้ ส่วนการคัดลอกข้อความไปวางทำไม่ได้แล้ว
- **คลิกแถบ Google ก็นับ:** การคลิกแถบแจ้งเตือนของ Google ด้านบนหน้า (อยู่นอกพื้นที่ข้อสอบ) นับเป็นการออกด้วย ควรบอกผู้สอบก่อนสอบ
- ผู้สอบที่ทำบนมือถืออาจถูกนับว่าออกจากหน้าสอบเพราะสายเรียกเข้า จอดับเอง หรือกดแจ้งเตือน ควรบอกให้เปิดโหมดห้ามรบกวนและตั้งให้จอไม่ดับก่อนสอบ
- การรีเฟรชหน้าก็นับเป็นการออกจากหน้าสอบหนึ่งครั้ง เพื่อปิดช่องโหว่ที่ปิดแท็บไปหาคำตอบแล้วเปิดกลับมาใหม่
- ระบบไม่ได้ยืนยันตัวตน ใครรู้รหัสนักศึกษาของคนอื่นก็เข้าสอบแทนได้ ผู้สอนควรตรวจชื่อกับรหัสในชีต
- ถ้าจะใช้ข้อสอบชุดนี้เป็นแบบทดสอบหลังเรียนด้วย ควรตั้ง `showAnswerKey: false` เพราะเมื่อผู้เรียนเห็นเฉลยแล้ว ผลสอบหลังเรียนจะเชื่อถือไม่ได้

## ทางเลือกสำรอง: Google Form แบบไม่จับเวลา

`google-form-no-timer/create_quiz_form.gs` ใช้สร้าง Google Form แบบ Quiz ที่มีข้อสอบและเฉลยชุดเดียวกัน แต่ **จับเวลาและตัดส่งอัตโนมัติไม่ได้** เพราะ Google Forms ไม่มีความสามารถนี้
วิธีใช้: วางไฟล์ในโปรเจกต์ Apps Script ใหม่ แล้วรันฟังก์ชัน `createQuizForm`
